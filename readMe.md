# 🌿 Âm'Nature

Site vitrine réalisé pour une naturopathe indépendante.

## 📖 Présentation

Âm'Nature est un site vitrine responsive conçu pour présenter les services d'une naturopathe, faciliter la prise de contact et permettre la réservation de consultations.

Le projet a été développé en HTML, CSS et JavaScript, sans framework, dans une démarche de création d'un site léger, performant et facilement maintenable.

---

## ✨ Fonctionnalités

- Accueil avec présentation de l'activité
- Présentation des accompagnements
- Prestations proposées
- Présentation de la praticienne
- Formulaire de contact
- Liens vers les réseaux sociaux
- Boutons de prise de rendez-vous (Calendly)
- Menu responsive
- Bouton "Retour en haut"
- Responsive mobile / tablette / desktop

---

## 🛠 Technologies utilisées

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Font Awesome

Services externes :

- Calendly (prise de rendez-vous)
- Formspree (formulaire de contact)
